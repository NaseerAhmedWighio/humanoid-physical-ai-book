## User Scenarios & Testing *(mandatory)*

### User Story 1 - Restore Original RAG Chatbot (Priority: P1)

Users should have access to the original RAG-based agent chatbot functionality without the additional text highlighter interface that was recently added. The chatbot should function as the primary AI assistant for answering questions about the humanoid robotics content using retrieval augmented generation.

**Why this priority**: This is the core functionality that users expect - a RAG-based chatbot that can answer questions about the content using the knowledge base. The text highlighter was an unnecessary addition that complicates the user experience.

**Independent Test**: Can be fully tested by interacting with the chatbot interface and verifying it responds to questions about the content using RAG capabilities, delivering the expected AI-powered assistance without the text highlighter.

**Acceptance Scenarios**:

1. **Given** user is on any content page, **When** user opens the chatbot interface, **Then** the original RAG-based chatbot is available for interaction
2. **Given** user has a question about the content, **When** user types the question in the chatbot, **Then** the chatbot responds using RAG capabilities with proper source attribution

---

### User Story 2 - Remove Text Highlighter Component (Priority: P1)

The text highlighter component that was added to the bottom of pages should be removed completely, simplifying the UI and removing the unnecessary "Ask Question" button that appeared when text was selected.

**Why this priority**: The text highlighter was not necessary and adds complexity without significant value. Removing it simplifies the user interface and focuses on the core functionality.

**Independent Test**: Can be tested by selecting text on any page and verifying that the "Ask Question" button does not appear, confirming the text highlighter functionality has been removed.

**Acceptance Scenarios**:

1. **Given** user selects text on any content page, **When** text is highlighted, **Then** no "Ask Question" button appears at the selection

---

### User Story 3 - Maintain Chatbot Persistence (Priority: P2)

The chatbot conversation history should continue to persist across page refreshes using localStorage, maintaining the user's conversation context.

**Why this priority**: Users expect their conversations to persist when navigating or refreshing pages, which was a previously working feature that should be maintained.

**Independent Test**: Can be tested by starting a conversation, refreshing the page, and verifying the conversation history is preserved.

**Acceptance Scenarios**:

1. **Given** user has an active chat session, **When** user refreshes the page, **Then** the conversation history is preserved

---

- **FR-001**: System MUST provide a RAG-based chatbot interface for answering questions about humanoid robotics content
- **FR-002**: System MUST remove the text highlighter component that appears when text is selected

- **FR-004**: System MUST maintain chat conversation persistence using localStorage
- **FR-005**: System MUST ensure the chatbot uses RAG (Retrieval Augmented Generation) to provide accurate responses based on the content knowledge base

- **User Message**: Individual messages sent by the user to the chatbot for processing
