# Data Model: Revert Text Highlighter and Restore RAG Chatbot

## Overview
This data model describes the entities and structures related to the chatbot functionality that will be preserved during the revert process.

## Entities

### Chat Conversation
- **Description**: Represents a user's conversation history with the AI assistant
- **Fields**:
  - `id` (string): Unique identifier for the conversation
  - `messages` (array): Array of message objects in the conversation
  - `createdAt` (datetime): Timestamp when conversation was created
  - `updatedAt` (datetime): Timestamp when conversation was last updated
  - `userId` (string): Identifier for the user (if applicable)
- **Storage**: localStorage with key 'chat_conversation'
- **Validation**: Must have at least one message, timestamps must be valid

### User Message
- **Description**: Individual messages sent by the user to the chatbot
- **Fields**:
  - `id` (string): Unique identifier for the message
  - `text` (string): The text content of the message
  - `sender` (string): Either 'user' or 'bot'
  - `timestamp` (datetime): When the message was sent/received
  - `conversationId` (string): Reference to the parent conversation
- **Validation**: Text must not be empty, sender must be valid value

### AI Response
- **Description**: Responses generated by the RAG system based on user questions
- **Fields**:
  - `id` (string): Unique identifier for the response
  - `text` (string): The text content of the response
  - `sources` (array): Array of source references used in the response
  - `timestamp` (datetime): When the response was generated
  - `conversationId` (string): Reference to the parent conversation
- **Validation**: Text must not be empty, sources should be valid references to content

### User Preferences
- **Description**: User preferences for personalization (preserved during revert)
- **Fields**:
  - `hardwarePreference` (string): 'mobile', 'laptop', or 'physical_robot'
  - `personalizationEnabled` (boolean): Whether personalization is active
  - `createdAt` (datetime): When preferences were set
  - `updatedAt` (datetime): When preferences were last updated
- **Storage**: localStorage with key 'userPreferences'
- **Validation**: hardwarePreference must be one of the allowed values

## State Transitions

### Conversation States
- `active`: Conversation is ongoing and messages can be added
- `archived`: Conversation is preserved but not actively used (localStorage cleanup)

### Message States
- `pending`: Message sent but waiting for response
- `received`: Message received and displayed
- `error`: Message failed to send or receive properly

## Relationships

### Chat Conversation contains User Message
- One-to-many relationship
- A conversation can have multiple messages
- Messages are ordered chronologically within a conversation

### Chat Conversation contains AI Response
- One-to-many relationship
- A conversation can have multiple AI responses
- Responses are interleaved with user messages

## Validation Rules

### Conversation Validation
- Must have a valid ID
- Messages array must not exceed localStorage size limits
- Must have valid timestamps

### Message Validation
- Text content must be between 1 and 2000 characters
- Sender must be either 'user' or 'bot'
- Must have valid timestamp

### Preference Validation
- hardwarePreference must be one of: 'mobile', 'laptop', 'physical_robot'
- personalizationEnabled must be boolean
- Cannot have conflicting preferences
